## 如何使用此目录

### 新增审查报告

1. 执行代码审查或分析
2. 在此目录创建文件，命名格式: `YYYY-MM-DD-topic.md`
3. 更新此 INDEX.md 列表
4. 提交 PR 时注明这是档案文档

### 查找历史信息

- 安全性问题 → 查看 2026-04-28 代码审查
- 架构决策 → 参考 `docs/ARCHITECTURE.md`
- 性能优化 → 参考 `docs/ADVANCED/`
